## 1차시 (45분)
학습 목표: 《월인석보》(1459)에 실린 세종어제훈민정음 서문을 읽고, 후기 중세 국어가 현대 국어와 어떻게 다른지 설명할 수 있다.

| 단계 | 시간 | 내용 |
|---|---|---|
| ① 도입 | 5분 | 국어사 연표, 생각 열기 |
| ② 원문 읽기 | 10분 | 낱말을 누르면 현대어 뜻과 문법 특징을 보여 주고, 특징별로 표시 |
| ③ 특징 탐구 | 20분 | 이어 적기, 합용 병서, 모음 조화, 주격 조사, 비교 부사격 조사, 동국정운식 한자음, 구개음화·두음 법칙, 어휘 변화 |
| ④ 확인 퀴즈 | 10분 | 6문항, 바로 채점 |

## 2차시 (45분)
학습 목표: 훈민정음의 제자 원리(상형, 가획, 이체, 천지인과 합성)를 이해하고, 이를 바탕으로 한글의 과학성을 설명할 수 있다.

| 단계 | 시간 | 내용 |
|---|---|---|
| ① 도입 | 5분 | 1차시 '스믈여듧 字' 복습, 28자 = 자음 17 + 모음 11 |
| ② 자음 만들기 | 15분 | 조음 위치별 기본자·가획자·이체자 표, '획 더하기' 체험 |
| ③ 모음 만들기 | 15분 | 천지인 기본자, 모음 만들기 체험(초출자·재출자, 양성·음성), 1차시 모음 조화와 연결 |
| ④ 퀴즈·정리 | 10분 | 7문항, 바로 채점, 생각 넓히기 |

옛한글은 '맑은 고딕'(Windows) 등 옛한글을 지원하는 글꼴에서 가장 잘 보입니다.
