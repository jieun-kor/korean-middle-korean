# 훈민정음 서문으로 배우는 중세 국어

중학교 2학년 국어 1차시(45분)용 HTML 수업 자료입니다.

**바로 보기:** https://jieun-kor.github.io/korean-middle-korean/

## 학습 목표
《월인석보》(1459)에 실린 세종어제훈민정음 서문을 읽고, 후기 중세 국어가 현대 국어와 어떻게 다른지 설명할 수 있다.

## 수업 흐름
| 단계 | 시간 | 내용 |
|---|---|---|
| ① 도입 | 5분 | 국어사 연표, 생각 열기 |
| ② 원문 읽기 | 10분 | 낱말을 누르면 현대어 뜻과 문법 특징을 보여 주고, 특징별로 표시 |
| ③ 특징 탐구 | 20분 | 이어 적기, 합용 병서, 모음 조화, 주격 조사, 비교 부사격 조사, 동국정운식 한자음, 구개음화·두음 법칙, 어휘 변화 |
| ④ 확인 퀴즈 | 10분 | 6문항, 바로 채점 |

## 사용 방법
- `index.html` 파일 하나로 되어 있어 인터넷 없이도 브라우저에서 열 수 있습니다.
- 옛한글은 '맑은 고딕'(Windows) 등 옛한글을 지원하는 글꼴에서 가장 잘 보입니다.
